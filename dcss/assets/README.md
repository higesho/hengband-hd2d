# DCSS（Dungeon Crawl Stone Soup）の絵の素材

決めたこと（2026-10-21）: 12 本目のコアとして取り込む DCSS 日本語版（`..\roguelike-cores\upstream\crawl-ja`、タグ `0.34.1-ja2`。2026-10-22 に ja4 へ上げたが `rltiles` は同じ）の
**絵は DCSS のタイルを使う。壁やオブジェクトはタイル画像をもとにボクセルのオブジェクトにする。
怪物・アイテム・プレイヤーは、ほかのコアと同じくタイルの絵をボクセルの板（かきわり＝ビルボード）にする。**
2026-10-21 の決定の追加: 怪物・アイテムの板は今のまま（32 ドットを 2 倍の 64）／壁はタイルに合わせて約 1 ボクセルの凹凸／祭壇・噴水などは絵を解釈して一から作る／
上り階段は下りの色調に合わせる／権利が確認できない絵もそのまま使う（使った絵と来歴を記録）。
このフォルダは作った物の置き場（検討は）。共通の `assets/` には何も書いていない。

| 置き場 | 中身 |
| --- | --- |
| `dcss/assets/slab/` | 怪物・アイテムの板 13 個（`.vox` ＋ `.jsonc`）。`.slab_manifest.json` は作り直しの控え。`tiles_used.tsv` は使った絵 |
| `dcss/assets/atlas/` | **段 M2 の材料**。原作のタイル版が使う画像ページ `main.png`・`player.png` と、タイルごとの切り出しの表 `tiles.tsv`（`tools/dcss/dcss_tile_atlas.py` が作る）。コアが実行時に、ここから怪物・アイテム・プレイヤーの板を作る（`dcss/adapter/README.md` §12）。上の 13 個は M0 の試作で、実行時には使わない |
| `dcss/assets/voxel/` | 地形・物のプレハブ 258 個（`.vox` ＋ `.jsonc`）。`manifest.tsv`（名前・種類・元の絵・DCSS の地形定義）と `tiles_used.tsv` つき |
| `dcss/assets/tile_provenance_unclear.tsv` | 来歴が CC0 と確認できない絵の一覧（crawl/tiles の全 1,264 項目と今の木の突き合わせ。§2） |
| `dcss/assets/tiles_used_provenance.tsv` | 本案件が使った絵の来歴の区分（§2） |
| `tools/dcss/inventory_tiles.py` | 棚卸し（分類ごとの枚数・画素の大きさ） |
| `tools/dcss/map_tile_defs.py` | 定義（`rltiles/dc-*.txt`）を読み、絵とゲームの物（列挙名）の対応表を作る |
| `tools/dcss/dcss_tiles_to_slabs.py` | 絵 → 板（既存の `tools/voxel/tile_to_slab.py` を呼ぶ薄い包み） |
| `tools/dcss/dcss_tile_atlas.py` | **段 M2**。原作の `tilegen` を画像つきで別に組み、画像ページと切り出しの表（`dcss/assets/atlas/`）を作る。`--check` で追跡中の物と一致するか確かめる |
| `tools/dcss/gen_dcss_terrain.py` | 地形の表（`dcss/terrain/feature_map.csv`）の全行 → ボクセルのプレハブ（壁・床・扉・階段・門・罠ほか）。`dcss_vox.py` が共通部分 |
| `tools/dcss/gen_dcss_objects.py` | 祭壇・噴水・像・木・店・隠し場所・台座・鉄格子を、絵を解釈して一から作る（`gen_dcss_terrain.py` が呼ぶ） |
| `tools/dcss/tile_provenance.py` | 来歴の突き合わせ（`--tiles-repo` に crawl/tiles の写し） |

- 定義との対応（`map_tile_defs.py`）: `dc-*.txt` の 19 ファイルが指す PNG は **7,457 枚**、定義に載らない PNG は **895 枚**（うち `UNUSED` 587）。
  定義は 1 行 1 枚で `<ファイル名> [<列挙名>]`（`MONS_JACKAL`・`WPN_DAGGER`・`DNGN_TREE` など）。`%sdir` で置き場、`%hue`・`%variation`・`%compose` などで色違い・重ね合わせを作る
  （`rltiles/tool/tile_list_processor.cc`）。**私の簡易な読み取りは `%compose` の合成・`%repeat` の展開を追っていないので、
  載らない 308 枚（`UNUSED` 以外）の一部は定義が合成で使っている可能性がある**（未確認。例: `dngn/floor/pedestal_*`・`crypt0..11`）。
  定義が指す先に実在しない行が 32 あった（`gui/backgrounds` の `enum:SP_RECOMMENDED_*` など、絵のファイルを持たない指定。内容は未確認）。
- 怪物の絵は種ごとに 1 枚（例 `mon/animals/jackal.png` = `MONS_JACKAL`）が基本。ゾンビ・骨・霊は `dc-zombie.txt` が別の絵を持つ。
  プレイヤーは `player/` の部品を `tiledoll.cc`・`tilemcache.cc` が重ねて 1 体にする（**この合成は未着手。§4 の残り**）。
- 実際にゲームが選ぶ絵（色違い・乱択の重み）は `tilepick.cc` が決める。ここでは読んでいない（**未確認**）。

## 3. 作ったもの

### 3.1 板（怪物・アイテム 13 個）

`python -u tools/dcss/dcss_tiles_to_slabs.py`（`--list` で名簿だけ）。32x32 を最近傍で 2 倍して 64x64（1 画素 = 2x2 ボクセル）にし、`tile_to_slab.py` へ渡す（今のまま）。

**アイテムの絵の選び方を直した（2026-10-21）**: 薬・巻物・ワンドなど「見た目がランダムな」アイテムは、原作が**見た目の下地の上に種類の札（`i-*`）を重ねて**描く
（`tilepick.cc` の `tileidx_known_base_item`、`tiledgnbuf.cc` の `add_main_tile`）。以前の `dc_pot_ambrosia` は札（`i-ambrosia`）だけを拾っていたので
「未鑑定の印」だけの絵になっていた。今は薬 = 瓶（`brown`）＋`i-label`＋札（薬の札は `dc-item.txt` の `%back i-label`）、
巻物 = `scroll`＋`scroll-<色>`＋札、ワンド = `gem_<材>`＋札の順に重ねる。`dc_pot_brown`（瓶だけ）は未鑑定の見た目として残した。
**残り**: 実機では下地（薬 22 色・ワンド 12 材ほか）× 札の組み合わせが要る。板を 1 個にまとめて作るか、2 枚重ねで描くかはアダプタ側の判断。

### 3.2 地形・物のプレハブ（258 個）

`python -u tools/dcss/gen_dcss_terrain.py`（`--list` で一覧、名前を渡せば 1 個だけ）。出力は `dcss/assets/voxel/`（`manifest.tsv` が名前・種類・元の絵・DCSS の地形定義の対応）。
**作る物の元は `dcss/terrain/feature_map.csv` の全行**（タイルのある 218 行。描かない 7 行を除く）。表の仕分け a・b の行も DCSS のタイルから作った物にそろえ、
そのため表は `dcss/terrain/build_feature_map.py` が `manifest.tsv` を読んで仕分けを c にそろえる（変えたのは道具の側。`--write` 済みで引数なしの照合は「最新」）。
約束は TOband と同じ（1 マス = 32 ボクセル、天面を z = 0、物は 3 ボクセル沈める）。`.jsonc` に材質（`stone` `wood` `metal` `plant` `clean` `leaf` ほか）を宣言した。

| 種類 | 個数 | 作り方 |
| --- | ---: | --- |
| 壁（wall） | 12 | 4 側面と天面にタイルを写し、**明るさの差で 3 段の凹凸（出っ張り・基準・へこみ。約 1 ボクセル）**を付ける。石の積み目・継ぎ目はへこみ、面は出っ張る |
| **地面（floor）・水と溶岩と泥（liquid）**・縦穴（pit） | **64**・7・1 | **タイルの平らな写しでなく、絵に合わせた凹凸のあるボクセルの物**。厚み 8 の板で、基準の天面は z = 6、凹凸は ±1 ボクセル（歩けるので低く）。**縁の 1 ボクセルは必ず基準の高さ**にして、隣のマスとの継ぎ目に段差が出ない（3x3 に並べて確かめた）。種類ごとの付け方: 石畳・板石 = 明るさで石ごとの高低と継ぎ目のへこみ／草・苔・蔦・粘液 = 明るい所に株、暗い所はくぼみ、乱数の塊で盛り上がり／砂・土・小石・塩 = ゆるい起伏に粒の明暗／水・溶岩・泥 = 天面を 2 下げて ±1（波・泡）。縦穴は絵の染みの形に掘る。暗すぎる絵は明るさを持ち上げた。**床 64 のうち 3 は表の地形（`DNGN_FLOOR`・塩・装飾の床）、61 はブランチごとの床**（`dc-floor.txt` の `FLOOR_*` の先頭の 1 枚。名前は `dc_floor_<列挙名>`。`dungeon_styles` から引く） |
| 扉（door） | 20（うち東西向き `_ew` 10） | 枠は厚み 12、扉板は 4 引っ込め、明るさで ±1。**開いた・壊れた扉は暗い所を抜いて向こうを見せる**。枠の側面・奥は輪郭の黒を内側の色に替えた（黒い塊に見えない）。敷居つき |
| 階段（stairs_up / stairs_down） | 1・2 | 上りは絵の輪郭が段の断面。**色は下りの明るさの分布に合わせた**（ヒストグラム整合）。下りは段状の穴。封印の下りは緑のまま |
| 門・入口・出口・ポータル・店跡・転送装置（gate） | 74 | 立てた板。輪郭の縁を厚み 11、内側を 5 にし、明るさで ±1。**権利の一覧に載る 4 種のポータルも元のタイルで作った**（`dc_gate_ice_cave_portal` など） |
| 罠・印・ハッチ（decal） | 21 | 絵を上から見た形で床に貼った厚み 1〜3 の浮き彫り |
| **祭壇（altar）** | **29** | **絵を解釈して一から作った**。段々の台（色は絵の下部から）に、神ごとの飾り: ジン=銀の棘の星、輝ける者=金の鷲と「1」、キクバークッガー=髑髏の山、イレデルヌル=紫縁の黒いオベリスク、ゾム=笑う石の顔、ヴェフメット=格子の青緑の板、オカワル=剣と盾、マクレブ=岩の上の炎、シフ・ムナ=氷の結晶、トグ=血の台の戦士と斧、ネメレクス=カードの扇の箱、エリヴィロン=聖杯、ルゴヌ=紫の渦の柱、ベオ=穴の開いた立石と火鉢、ジーヴァ=緑の粘液球、フェダス=蔦と果実の板と太陽、チェイブリアドス=砂時計とカタツムリ、アシェンザリ=割れた像と赤い割れ目、ディスメノス=暗い宝珠と紫の輪、ゴザーグ=金のダイヤと光輪、カザラル=橙の角と稲妻、ルー=天秤、諸神共通=墓石と蝋燭、パケラス=桃色の宝珠の天球儀、ウスカヤウ=太鼓、ヘプリアクラカナ=苔の石板と青緑の霊気、武剣=鳥居と提灯、イグニス=崖と火、未鑑定=「?」 |

| 像（statue） | 6 | 台と宝珠を一から作った（ゾットの火・冬・エントロピー、金属の三角枠）。オークの偶像・花崗岩の像（ドワーフ）は台を作り、人形は絵の輪郭の浮き彫り |
| 木（tree） | 4 | 幹・枝・葉を一から作った（木・石化・マングローブ・悪魔の木。色は絵から） |
| 店（shop） | 7 | 露店（台・柱・縞の日除け・看板・売り物。看板と売り物の色は絵から） |

- 色は 1 個 255 までが `.vox` の上限。絵から写す物は**メディアンカットで 80〜128 色に詰め**（元の色数と詰めた枚は道具の最後に申告）、奥の面の暗い色を足しても 255 に収めた。

- 前の試作の 8 個は、同じ名前で作り直した（`dc_wall_catacombs` は表にない前の試作の名前なので残した。`dc_floor_rect` は `dc_floor_vault`〔`FLOOR_VAULT`、同じ絵〕になった）。

### 3.3 確かめ方と結果（確かめた事実）
