# Angband 4.2 日本語カタログ（画面の字）
#
# 読むのは AngbandCore.exe の an::lang_init
# （angband/adapter/an_lang.cpp）。この原本は UTF-8 で、コアの中も UTF-8（CP932 への変換は無い）。
#
# ------------------------------------------------------------------ 書き方（Frox と同じ）
#
#   E:  英語の原文（= 鍵）。1 バイトでも違えば別物なので、**正規化しない**
#   J:  訳文
#   #   註記
#
#   札（どれも別の表。混ぜない）:
#     E:  一般。3 か所で引く——書式（vstrnfmt() の頭。フック #2）・Term へ書く字を丸ごと
#         （Term_addstr() の頭。末尾の空白を除いて一致したら元の桁まで空白で埋める。フック #1）・
#         アダプタ自身の字（an::ui_text()）・問いの字（get_item()/get_check() の pmt。フック #13 #15）
#     A:  `%s` に裸で入る語（equip の部位名・`Wielding`・`When eaten, it ` ほか。フック #3）
#     R:  組み上がった行の中の句（`my_strcat()` で継ぐ見出し。フック #14）
#     V:  組む前の英語の句（怪物のメッセージの述語・打撃の型・動詞。an_tr_v()/an_tr_pred()。P2 のフック #19〜#21）
#     T:  「見る」（l）の 1 行の説明の句（怪物の状態 `unhurt` `asleep` ほか・地形の冠詞の句。
#         an_look_health()/an_look_feature()。AH-59。読むのは an_targeting.c の an_look_describe_grid() だけ）
#     H:  死因のうち怪物でないもの（`starvation` `poison` ほか。`take_hit()` の最後の引数）。**訳文の頭に `{H}` を
#         書いた書式**（墓の `by %s.`・殿堂の `Killed by %s ...`）の引数だけ引く（ほかの `%s` へは効かない）。
#         罠の名（`a pit`）と殿堂の記録で 31 バイトに切れた句はアダプタが引く（death_cause_ja()。AH-60）
#
# 1 件は E:（または A:/R:）と J: の 2 行。行頭・行末の空白は `\s`、改行は `\n` と書く。
#
# ------------------------------------------------------------------ 決まり
#
# - **変換指定（%d %s %c …）の並びは英日で一致していること。** 食い違う訳は読み込みで弾かれる。
#   引数を出したくないときは精度 0（`%.0s`）で読み捨てる（複数形の `s` など）。
# - **`[y/n]` を含む鍵は訳文にも `[y/n]` を残す**（アダプタが「はい／いいえ」の桁を取る。設計 §8）。
# - **アダプタが画面を見分ける目印の文言は、目印そのもの（E:）の訳が画面に出る訳文の中に同じ字で
#   入るときだけ訳す**（an_main.cpp の starts_with_marker()/contains_marker() は英語と E: の訳の両方を
#   見る）。2026-09-27（§20）に `Command: `・`New `・`Key:`・`Map sector`・`Direction?`・誕生の脚注を
#   この形で訳した。`-more-`・`Repeat: %d` は訳さない。訳すときは an_main.cpp の selftest の目印の表にも足す。
# - 訳に曖昧幅の字（…・×・○・★ ほか）を使わない（全角 2 桁の判定を W/F だけで行うため。an_wide.c）。
# - 引けなかった鍵は英語のまま出る（制約 5）。
#
# 範囲（2026-09-27）: 新 UI のメニューの窓に載る字——コマンドの名前と分類・アダプタの字・
# アイテムを選ぶ問いと見出し・装備の部位・名前の飾り・無視のメニュー・アイテムの文脈メニュー・
# 確認と数量・アイテムを調べる窓の骨組み。
# 2026-09-27 に P2（メッセージ。末尾の「P2: メッセージ」の節）を足した。gamedata の説明文（P3）は lib-ja。
