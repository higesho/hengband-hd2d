# TOband -> English: quest names and quest text (q*.txt in lib/edit).
# Format: I: quest number / J: Japanese name (for cross-check) / N: English name / T: text lines.
# Only quests whose English is missing, incomplete, different from the Japanese or the game, or spelled
# differently from the glossary (Tactics Ogre portable edition spellings) are listed.
# A quest with a good English name already in the original file has no N: line.
# Each group of T: lines is the full English text of one block (the block is named in the comment).
# A comment line beginning with REPLACES says which original English lines (the Q:$no:N: or Q:$no:T: lines
# of the named file, by file line number) this entry takes the place of. Without it, the original had no English.
# Kinds: NEW (no English before), REWRITE (the old English said something else than the Japanese and the
# game), SPELLING (old English kept, only proper nouns changed to the glossary spelling), SPELLING+ADD (the
# same, and the missing part of the Japanese added).
# Original rule (init1.c, English build): only lines written as Q:$<no>:N: and Q:$<no>:T: are read;
# lines without the $ are the Japanese ones and are skipped. quest_text is char[10][80], so one block
# is at most 10 lines of at most 79 characters, and the characters colon, slash and backslash must
# not appear in a value (tokenize() splits on them).
# A T: line with nothing after it is an empty line. Empty lines count toward the 10.
