# silq/lang/ja/ui/messages.ja.txt
#
# 表示文字列のカタログ。
#
#   E:  鍵。C の文字列リテラルの中身そのまま。\n \t \r \\ と、
#       行頭・行末の空白 1 個ぶんの \s を解く。**それ以外は正規化しない**
#       ――1 バイトでも違えば別の鍵である
#   J:  訳文。**空なら「わざと訳さない」の印**（未訳一覧から外れる）
#   W:  任意。桁を合わせたい鍵の幅（バイト）。tools/silq/check_ja.py が見る
#
# 符号は UTF-8・改行は LF。コアが読むときに CP932 へ直す（設計 §3.1）。
#
# ---------------------------------------------------------------------------
# **いまは P0（道の試し）＋ P2（基の名）＋ P3（メッセージ）が入っている。**
# 画面まわり（キャラクターシート・設定・誕生）は P5 でここへ足す。
#
# 直す前に読むもの:
#   * 用語表 silq/lang/ja/glossary.md（**`決` の行は勝手に変えない**）
# * 設計 （フック 10 か所）と §8.2（未訳の仕分け）
#
# 検査:
#   python tools/silq/check_ja.py            鍵の重複・型の食い違い・CP932・桁
#   python tools/silq/sq_untranslated.py     まだ訳していない鍵を段ごとに数える
#   python tools/silq/sq_p3_playthrough.py <workdir>   通しで遊んで文言を並べる
#
# 覚え書き:
#   * `%.0s` は「引数を食って何も出さない」印。英語の文法をつなぐだけの引数
#     （"Y" / "was" / 複数形の "s"）を捨てる。数を減らすと後ろがずれるので消せない
#   * `%^s` の `^` は日本語では何もしないが、**並びを合わせるため残す**
#   * 会心の段を表す末尾の `%s`（`.` `!` `!!`）は ASCII のままにする
# ---------------------------------------------------------------------------
