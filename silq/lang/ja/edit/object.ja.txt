# silq/lang/ja/glossary.md（承認済み 版 1.0）。
#
# ## `&` と `~` は残す（設計 §6.3）
# `& ダガー~` の形のまま焼く。`init1.c` の解析器に触らないためで、
# **落とすのは表示のとき**（`sq_object_desc_ja()`。P2）。
# `~` の位置は日本語では意味を持たないので**末尾に置く**。
# `& Pair~ of Boots` のように英語で途中に付いているものも、日本語では
# `& 長靴~` のように 1 語へ畳む（「一組の」は助数詞の仕事。設計 §6.3）。
#
# ## 「of X」の側（`Ring~` と `Evasion` は別項目）
# Sil-Q は基の名（`& Ring~`）と銘（`Evasion`）を別の項目で持ち、
# `object_desc()` が `" of "` で繋ぐ（`object1.c:914`）。
# **P1 の間は「指輪 of 回避」と出る。** 直すのは P2（`sq_object_desc_ja`）で、
# そこで「回避の指輪」に組み替える。**銘は常に前**（用語表 §7）。
#
# ## 訳し分けた語（用語表への追記が要る所）
# - `Protection` … 技能としては「防護」、アイテムの銘としては「守り」
#   （`守りの指輪` のほうが読める。用語表 §2 と §7 の例に合わせた）
# - `Slowness`（薬）は「遅鈍」。最下段の帯の `Slow`（鈍足）と**別の語にする**
#   ——同じ字だと「薬を飲んだ」のか「状態異常になった」のか読み分けられない
