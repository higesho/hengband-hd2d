#   I: **並び順**（1 始まり。history の `N:` は 4 つの数で通し番号ではない）
#   E: 英語の原文（照合用）/ N: 日本語
#
# **この表だけ訳を `N:` に書く。** history の説明文は `D:` に入っているが、
# あれは「名前」の位置に当たる（`build_ja_edit.py` の `KINDS` が `history` を
# 別扱いしている）。`sq_p4_desc.py todo history` もその形で出す。
#
# ## 断片は 1 つずつ文として閉じる（**継ぎ目には空白が入る**）
#
# `birth.c:97-126` の `get_history()` が chart を辿って断片を継ぎ足すが、
# **1 つ足すごとに空白を 1 つ入れる**（`birth.c:122` の `my_strcat(..., " ")`）。
# だから「あなたは数人兄弟の一人であり、その親は」＋「弓兵であった。」のように
# **助詞で繋ぐ形は使えない**——`親は 弓兵であった。` と割れて出る（実測した）。
#
# 設計 §6.4 のとおり**断片ごとに「〜。」で閉じる**:
#
#   I:1「あなたは数人兄弟の一人である。」＋ I:5「親は弓兵であった。」
#   ＋ I:10「フェアノール家の出である。」
#
# 見た目（chart 25〜28・50〜52・54〜56・57〜61）も同じ作りで、
# 「目は焦茶色。」「髪は真っ直ぐ。」「髪の色は黒。」「肌の色は並。」と並ぶ。
# **chart 52 と 56 だけは髪の色と肌が 1 つの断片**なので
# 「髪の色は黒で、肌は色白。」の形にしてある。
#
