# 技能の能力（アビリティ）の名前。書式は。
#
# ## 同じ名が 4 回出る
# `Strength` `Dexterity` `Grace` `Constitution` は**技能の木ごとに別項目**で
# 同じ名を持つ（打撃の腕力・射撃の敏捷…）。通し番号は別だが訳は 1 つでよい。
#
# ## 訳の当て方
# **働きを見て当てた**（`D:` を全部読んだ）。字面だけで訳すと外す:
# `Rout` は「敗走」ではなく**逃げる敵を狙い撃つ**技、
# `Channeling` は「導管」ではなく**杖と角笛を使いこなす**技、
# `Outwit` は**相手の会心を知覚で打ち消す**技である。
#
# 歌（`Song of ...`）は用語表 §3 の決定に従う。

# ## `D:`（説明文）は P4 で足した（84 件）
#
# 2026-08-21。折り方・道具・禁則の扱いは `monster.ja.txt` の頭に書いてある
# （`python tools/silq/sq_p4_desc.py todo <表> / apply <表> <patch>`）。
