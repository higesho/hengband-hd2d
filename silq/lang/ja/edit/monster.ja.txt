# silq/lang/ja/edit/monster.ja.txt
#
# 敵の名前。書式は 、訳語は
# silq/lang/ja/glossary.md（承認済み 版 1.0）。
#
#   I:  通し番号 / E: 英語の原名（照合用）/ N: 日本語の名前 / D: 思い出
#
# **`D:` は P4 で足した**（2026-08-21。125 件）。`D:` の行は焼くときに
# **前後の空白を入れずにそのまま繋がれる**ので、日本語では好きな所で折ってよい
# （英語の `D: ` の頭の空白は、あちらが語の区切りに要るから付いている）。
# 折り返しと禁則は画面側が行う（`sq_break` / `sq_wrap_here`。設計 §4 の #4/#5）。
# 未訳を出す・訳を差し込むのは `python tools/silq/sq_p4_desc.py`。
#
# ## 訳の作法（用語表 §7 の写し）
# - **称号は訳し、名は音写する。** `Morgoth, Lord of Darkness` → `暗黒の王モルゴス`
#   （英語の「名, 称号」の順は保たない）
# - `the` / `a` は落とす
# - **`rauko` 系 6 体は意訳**（決めたこと。用語表 §9 の問 5）
#
# ## 名の族を揃える
# 同じ語尾を持つ一群は日本語でも揃える。ばらけると別物に見える:
# `-thorn` は「茨」（絡み茨・狂い茨・夜の茨）、`horror` は「恐怖」、
# `wight` は「亡者」（ただし `Barrow wight` は指輪の既訳「塚人」）、
# 宝石の大蛇は「青玉／紅玉／翠玉／紫水晶／金剛石」で揃える。
