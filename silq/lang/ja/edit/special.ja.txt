# アイテムの銘（`守りの鎖帷子` の「守りの」の側）。書式は。
#
# ## **銘は常に前**（用語表 §7）
# 英語は `Mail Corslet of Protection` と後ろに置くが、日本語は
# `守りの鎖帷子` と前に置く。だからここの訳は**「〜の」で終える**。
# 組み替えるのは `sq_object_desc_ja()`（P2）で、**P1 の間は後ろに出る**。
#
# ## 括弧付きの 4 つ
# `(Poisoned)` `(Balanced)` `(Defender)` `(Vampiric)` は英語でも
# 名の後ろに括弧で付く別枠。日本語でも括弧のまま後ろに置く。
#
# ## 地名・種族は用語表 §4 に従う
# `of Nogrod` → `ノグロドの`。ドワーフの 7 氏族（`Firebeards` `Longbeards`
# `Ironfists`）は**「〜族の」**で揃える。
