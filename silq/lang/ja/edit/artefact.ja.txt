# ## 2 つの形がある
# - `'Angrist'` … 固有の銘。`『アングリスト』` と**二重鉤括弧**で包む（変愚と同じ）
# - `of Barahir` … 人名・地名。`バラヒアの` と**「〜の」で終える**
#
# **銘は常に前**（用語表 §7）。英語は `Dagger 'Angrist'` と後ろに置くが、
# 日本語は `『アングリスト』のダガー`。組み替えるのは P2。
#
# ## 意味の見える銘は**音写する**（決めたこと。用語表 §9 の問 6）
# `'Silverhand'` → `『シルヴァーハンド』`（`『銀の手』` ではない）。
# `'Thorn'` `'Starlight'` `'Catskin'` `'Ultimate'` も同じ。
# ただし `'Ungoliant's Lament'` と `of Mothers' Woe` は**所有格の句**なので訳す
# ——音写すると日本語として読めない。
#
# ## 同じ銘が何度も出る
# `'Ultimate'` は 18 項目、`of Morgoth` は 4 項目ある（鍛冶で作る器の枠）。
# 通し番号は別だが訳は 1 つ。
